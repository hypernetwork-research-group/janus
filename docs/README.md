# Janus — Hypergraph Generation with Latent Diffusion

A static project website inspired by the Nerfies research project template (https://github.com/nerfies/nerfies.github.io).

## Publish

Upload the **contents** of this directory to the root of a GitHub repository, enable GitHub Pages in **Settings → Pages**, and publish from the main branch root. Open `index.html` locally to preview. No build step or server required.

## Contents

- `index.html`, `styles.css`, `script.js`: website
- `janus-logo.png`: supplied Janus title artwork
- `assets/figures/`: original figures and charts
- `assets/tables/`: original LaTeX tables, also rendered as HTML in collapsible panels
- `paper_source.tex`, `appendix_source.tex`, `complete_latex_sources.zip`: paper source material

The BibTeX at the bottom is a manuscript citation rather than a publication claim; revise the venue and publication details after acceptance/publication.
